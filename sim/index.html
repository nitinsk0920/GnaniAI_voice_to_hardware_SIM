Voice-to-Hardware Simulator

Build a circuit, then chat with the agent. It writes the Arduino code, runs it, measures the pins, fixes itself until it works, and explains every line.

Circuit

Click buttons and turn knobs while the code runs. "~" marks PWM pins (needed for fading, brightness and other analogWrite effects). Wires: colored = signal, red = 5V, black = GND.
