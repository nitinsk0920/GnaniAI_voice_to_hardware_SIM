Voice-to-Hardware Simulator

Build a circuit, then chat with the agent. It writes the Arduino code, runs it, measures the pins, fixes itself until it works, and explains every line.

Your API keys

Keys stay in this browser. They are sent only with your own requests, and the server uses them for that request without storing or logging them.

This server also has keys of its own (.env): fields left empty use those.

Circuit

Click buttons and turn knobs while the code runs. "~" marks PWM pins (needed for fading, brightness and other analogWrite effects). Wires: colored = signal, red = 5V, grey = GND.
